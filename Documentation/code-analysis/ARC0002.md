---
title: 'ARC0002: Command-like class is not decorated'
description: Mark handler-shaped classes as Arc commands.
---

## What

A class defines `handle()` without `@command()`. Rule: `arc-core/arc0002`.

## Why

Arc does not discover an undecorated command; `handle()` alone is not a route.

## Bad

```ts
export class Register { handle() {} }
```

## Good

```ts
@command()
export class Register { handle() {} }
```

If the class is a service rather than a command, rename its method.
