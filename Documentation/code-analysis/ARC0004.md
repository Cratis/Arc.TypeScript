---
title: 'ARC0004: Command has no public handle'
description: Put a public instance handler on each decorated command.
---

## What

`@command()` requires a public instance `handle()` method. Rule: `arc-core/arc0004`.

## Why

Static, private, protected, or missing handlers cannot be invoked as command handlers.

## Bad

```ts
@command()
export class Register { private handle() {} }
```

## Good

```ts
@command()
export class Register { handle() {} }
```
