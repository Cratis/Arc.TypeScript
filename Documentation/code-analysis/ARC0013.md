---
title: 'ARC0013: Not applicable in Arc for TypeScript'
description: Validator selectors are captured as paths rather than evaluated on input.
---

ARC0013 is not implemented by the TypeScript ESLint plugin. `ruleFor` records the selector path through a Proxy; it never executes the selector against the input model. Validation walks that path null-safely and unwraps concept values automatically, so accessing `input.title.value` in the selector does not throw before a rule runs. There is no corresponding rejection rule to enable.
