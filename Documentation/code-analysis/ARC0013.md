---
title: 'ARC0013: Validator dereferences a concept'
description: Validate the concept before accessing its members.
---

## What

A `ruleFor` selector dereferences a member of a `ConceptAs` value. Rule: `arc-core/arc0013` (requires type information).

## Why

Deserialized input may contain a missing concept; dereferencing it throws before validation can report an issue.

## Bad

```ts
this.ruleFor(input => input.title.value).notEmpty();
```

## Good

```ts
this.ruleFor(input => input.title).notEmpty();
```
