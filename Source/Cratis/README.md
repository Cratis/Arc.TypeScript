# @cratis/cratis

Experimental Arc and Chronicle composition for Node.js. `CratisApplication.createBuilder()` and `builder.addCratis()` register Chronicle without choosing an authentication handler. The `./testing` export re-exports Arc and Chronicle testing helpers.

This package is part of the source preview and is not yet published to npm. See the [package reference](https://github.com/Cratis/Arc.TypeScript/blob/main/Documentation/reference/packages.md) and [Chronicle integration guide](https://github.com/Cratis/Arc.TypeScript/blob/main/Documentation/chronicle/add-event-sourcing.md) for usage and current limitations.
