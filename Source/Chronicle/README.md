# @cratis/arc.chronicle

Experimental Chronicle integration for Arc for TypeScript. Live-kernel integration checks cover selected command and read-model flows through Express, Fastify, and Hono, alongside the Library sample. These checks do not establish full parity with Arc on .NET; see the [capability reference](https://github.com/Cratis/Arc.TypeScript/blob/main/Documentation/reference/capabilities.md#chronicle-checks) for coverage and remaining limits.

See the [Chronicle integration documentation](https://github.com/Cratis/Arc.TypeScript/blob/main/Documentation/chronicle/add-event-sourcing.md) and [package reference](https://github.com/Cratis/Arc.TypeScript/blob/main/Documentation/reference/packages.md).
