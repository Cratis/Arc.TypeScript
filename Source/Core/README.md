# @cratis/arc.core

Host-independent Arc command and query runtime for Node.js, with a standalone HTTP host. Does not require Chronicle or a database.

See the [core getting started guide](https://github.com/Cratis/Arc.TypeScript/blob/main/Documentation/core/getting-started.md) and [package reference](https://github.com/Cratis/Arc.TypeScript/blob/main/Documentation/reference/packages.md).
